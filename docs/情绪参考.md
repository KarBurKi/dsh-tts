# 情绪参考音频

三组参考都在 `refs/`，32 kHz 单声道，长度落在 GSV 要求的 3~10 秒内。

| 组 | 素材编号 | 时长 | prompt_text |
| --- | --- | --- | --- |
| `soft` | 022 | 8.23 秒 | 见到我很意外吗？哈哈，别紧张嘛，我说过我们会再见面的。 |
| `playful` | 108 109 112 113 114 | 9.35 秒 | 在这哦~一点惊喜！非要打架吗？差不多了吧？好累，让我歇会…… |
| `threat` | 118 119 150 | 5.29 秒 | 安静！不许动！好吧，又来？ |

## 怎么拼的

每条之间 `apad=pad_dur=0.30` 补气口，**最后一条必须给 0**——按 `pad×(n-1)` 估算会少算，实测两组落到 10.09 / 10.01 秒被 GSV 400 直接拒绝。

```bash
ffmpeg -y -i 118.wav -i 119.wav -i 150.wav -filter_complex \
  "[0:a]apad=pad_dur=0.30[a0];[1:a]apad=pad_dur=0.30[a1];[2:a]apad=pad_dur=0.0[a2];[a0][a1][a2]concat=n=3:v=0:a=1[out]" \
  -map "[out]" -ar 32000 -ac 1 threat.wav
```

## 挑素材的两条硬规矩

1. **一组里语气必须统一**。硬软混搭，模型学到的是「每句在两种语气间跳」，听起来忽上忽下。
2. **气声重的素材别当威胁用**。参考里气声重，模型照着学，威胁听起来像要断气。

## 角色口径

主人对达尼亚的原话：「你不会凶我」，凶的时候语气俏皮一点反倒更可怕。所以这一格叫 `threat` 而不是 `angry`——她要是扯着嗓子喊，反而不像她。
